# Documentation du portfolio

Cette documentation couvre l'architecture, les services, les hooks et les types du portfolio.

## Structure

- `docs/docs` : pages de documentation generales.
- `docs/docs/api` : reference API generee par TypeDoc.

## Demarrer la doc

```bash
pnpm docs:dev
```

## Generer l'API Reference

```bash
pnpm docs:api
```
