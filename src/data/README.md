# Donnees

Ce dossier contient toutes les donnees statiques du site au format JSON.
Ces fichiers sont prevus pour etre remplaces par une API Strapi.

## Fichiers

### blog.json

- Structure : Array<BlogPost>
- Usage : contenu des articles de blog

### projects.json

- Structure : Array<Project>
- Usage : projets du portfolio

### services.json

- Structure : Array<ServiceItem>
- Usage : services mis en avant sur la page d'accueil

### partners.json

- Structure : Array<Partner>
- Usage : partenaires affiches sur la section A propos

### cv.json

- Structure : objet compose (profil, competences, experiences, formations)
- Usage : contenu de la page CV
