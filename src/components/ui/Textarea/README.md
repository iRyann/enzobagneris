# Textarea

Champ multiligne reutilisable.

## Import

```typescript
import { Textarea } from '@/components/ui';
```

## Usage

```tsx
<Textarea rows={5} placeholder="Votre message" />
<Textarea variant="underline" />
```

## Props

| Prop    | Type                          | Default   | Description |
| ------- | ----------------------------- | --------- | ----------- |
| variant | 'default' \| 'underline'       | 'default' | Style visuel |
