# Input

Champ de saisie reutilisable.

## Import

```typescript
import { Input } from '@/components/ui';
```

## Usage

```tsx
<Input placeholder="Votre email" />
<Input variant="underline" placeholder="Sujet" />
```

## Props

| Prop    | Type                          | Default   | Description |
| ------- | ----------------------------- | --------- | ----------- |
| variant | 'default' \| 'underline'       | 'default' | Style visuel |
