# Section

Section de page avec variants de fond.

## Import

```typescript
import { Section } from '@/components/ui';
```

## Usage

```tsx
<Section>...</Section>
<Section variant="light">...</Section>
<Section variant="dark">...</Section>
```

## Props

| Prop    | Type                           | Default   | Description |
| ------- | ------------------------------ | --------- | ----------- |
| variant | 'default' \| 'dark' \| 'light' | 'default' | Style de fond |
