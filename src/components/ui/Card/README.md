# Card

Conteneur reutilisable pour sections et blocs de contenu.

## Import

```typescript
import { Card } from '@/components/ui';
```

## Usage

```tsx
<Card>Contenu</Card>
<Card variant="bordered">Contenu</Card>
<Card variant="elevated">Contenu</Card>
```

## Props

| Prop    | Type                                 | Default   | Description |
| ------- | ------------------------------------ | --------- | ----------- |
| variant | 'default' \| 'bordered' \| 'elevated' | 'default' | Style visuel |
