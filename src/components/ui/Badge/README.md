# Badge

Petit label pour tags et statuts.

## Import

```typescript
import { Badge } from '@/components/ui';
```

## Usage

```tsx
<Badge>Tag</Badge>
<Badge variant="accent">Accent</Badge>
<Badge variant="soft">Soft</Badge>
```

## Props

| Prop    | Type                           | Default   | Description |
| ------- | ------------------------------ | --------- | ----------- |
| variant | 'default' \| 'accent' \| 'soft' | 'default' | Style visuel |
